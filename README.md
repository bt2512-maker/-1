# Сайт «Бульбашка»: публікація на GitHub Pages

Це статичний сайт: `index.html`, `css/style.css`, `js/app.js`, фото в `images/`.
Послуги лежать у `data/services.json`. Адмін-панель змінює цей файл прямо в репозиторії через GitHub.

## 1. Опублікувати сайт

1. На github.com натисніть **New repository**, назвіть, наприклад, `bulbashka`, оберіть **Public**, натисніть **Create repository**.
2. Розпакуйте архів. Відкрийте репозиторій, натисніть **Add file → Upload files** і перетягніть **вміст** розпакованої папки
   (файли `index.html`, `404.html`, папки `css`, `js`, `images`, `data`, `uploads` і файл `.nojekyll`), а не саму папку.
   **`index.html` має лежати в корені репозиторію**, інакше GitHub покаже помилку 404.
   Натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**,
   гілку **main** і папку **/ (root)**, натисніть **Save**.
4. Через 1–2 хвилини сайт з'явиться за адресою `https://ВАШ-ЛОГІН.github.io/bulbashka/`.

Якщо файли не відображаються як у корені, перевірте, що в списку репозиторію одразу видно `index.html`, а не папку з ним.

## 2. Налаштувати адмін-доступ (один раз)

1. На GitHub: **Settings (вашого акаунта) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Назва: `bulbashka-admin`. Термін дії: на ваш вибір (наприклад, 1 рік).
3. **Repository access → Only select repositories** і оберіть лише цей репозиторій.
4. **Permissions → Repository permissions → Contents: Read and write**. Натисніть **Generate token** і скопіюйте токен.
5. Відкрийте свій сайт, внизу натисніть кнопку **Адмін**. Вставте токен і придумайте пароль (від 12 символів).
   Можна взяти пароль `GCEN-8JTD-4AEY`.
6. Токен шифрується вашим паролем і зберігається у файлі `data/admin.json`. Надалі вхід лише за паролем.

Після входу з'являються «Керування послугами» та адмін-панель. Зміни зберігаються комітом у репозиторій
і з'являються на сайті приблизно через 1–2 хвилини.

## Безпека, коротко

* Токен доступу дає запис лише в цей репозиторій. Нікому його не показуйте.
* `data/admin.json` публічний, але розшифрувати його можна тільки паролем. Використовуйте довгий пароль.
* Забули пароль або закінчився термін токена: видаліть файл `data/admin.json` у репозиторії, створіть новий токен і пройдіть крок 2 знову.
* Кнопки «Адмін» на сайті недостатньо для зміни даних: без токена GitHub не дозволить записати жодної зміни.

## Власний домен

Якщо підключите свій домен, відкрийте `js/config.js` і впишіть `owner` (ваш логін GitHub) та `repo` (назва репозиторію).

## Редагування вручну

Послуги можна змінити й без адмін-панелі, відредагувавши `data/services.json` на GitHub. Фото кладіть у `uploads/`
і вказуйте шлях виду `uploads/назва.jpg`.
